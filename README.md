# 📝 Task Flow | Gerenciador de Tarefas Interativo

Uma aplicação web moderna e responsiva para gerenciamento de tarefas diárias, desenvolvida com **HTML5 semântico, CSS3 moderno e JavaScript puro (ES6+)**.

---

## 📌 Sobre o Projeto / About The Project

O **Task Flow** foi criado para proporcionar uma experiência fluida de organização pessoal, permitindo cadastrar, filtrar e acompanhar o status de atividades diárias sem perder as informações após fechar o navegador.

### Principais Funcionalidades / Key Features:
* **Persistência de Dados (`localStorage`):** Suas tarefas ficam salvas localmente no navegador.
* **Manipulação Dinâmica do DOM:** Criação, conclusão e exclusão de itens em tempo real.
* **Filtros Interativos:** Visualize tarefas *Todas*, *Pendentes* ou *Concluídas*.
* **Design Responsivo:** Interface adaptada para navegação em dispositivos móveis e desktop.
* **Contador Dinâmico:** Monitoramento automático da quantidade de pendências.

---

## 🛠️ Tecnologias Utilizadas / Tech Stack

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Flexbox, layout responsivo e variáveis de design escuro (*Dark Mode UI*).
* **JavaScript (ES6+):** 
  * Métodos de iteração (`filter`, `map`, `forEach`)
  * Manipulação de eventos (`addEventListener`)
  * Armazenamento web (`localStorage` e `JSON parse/stringify`)
